PUNCH

Judge guide — how to test PUNCH

5 minutes, real devnet transactions the whole way
Step 1

Install

cd punch-native
npm install
npx expo start -c

Scan the QR code with Expo Go, or install a dev build on a Solana Seeker phone / any Android device with a Mobile Wallet Adapter–compatible wallet (Phantom, Solflare) set to devnet.

Step 2

Connect for real

On the "CLOCK IN" screen, tap connect. This opens Mobile Wallet Adapter and asks you to authorize on devnet — use a real wallet, not the demo fallback.

A brand-new wallet starts at zero (correct — it's real). Within seconds the app sends a real welcome grant from its treasury: 0.05 SOL, 5 USDC, 20 USDT-devnet, 5,000 SKR-devnet.
Step 3

Punch in

Tap the bolt — signs a real memo transaction (PUNCH <date>) on devnet. You get a paper-style ticket: time, country, 92/3/5 rule, on-chain stamp.

Step 4

Try the money features

  • Board → Pay someone: locks real funds into the treasury.
  • A job → Get paid: treasury sends the worker's share to your wallet.
  • Wallet → Swap: two real transfers at a fixed rate.
  • Wallet → Stake / Unstake: real SPL transfers, 1.5% real fee on unstake.
  • Home → Say hi: treasury pays you $0.10 USDC.
  • Settings/Split → Leave the network: real "leave" transaction, honest counter decrement.
Step 5

What to look at as a judge

  • Every action above should trigger your wallet's signing prompt.
  • Treasury address: FUiCbnDhEEJtz9Zcj66hGB54iGMGeyjRKD7CsTwpihJn — check it on a devnet explorer before/after.
  • The globe (World tab) uses real drag physics — momentum, natural decay.
  • Try the interactive guide from Settings ("Start the tour").
  • Try the Gold theme in Settings.
Étape 1

Installer

cd punch-native
npm install
npx expo start -c

Scanne le QR code avec Expo Go, ou installe un build de dev sur un téléphone Seeker / tout Android avec un wallet compatible (Phantom, Solflare) réglé sur devnet.

Étape 2

Se connecter en vrai

Sur l'écran « CLOCK IN », touche connexion. Ça ouvre Mobile Wallet Adapter, autorisation sur devnet — utilise un vrai wallet, pas le mode démo.

Un wallet neuf démarre à zéro (normal — c'est réel). En quelques secondes, l'app envoie un vrai lot de bienvenue depuis le trésor : 0,05 SOL, 5 USDC, 20 USDT-devnet, 5 000 SKR-devnet.
Étape 3

Pointer

Touche l'éclair — signe une vraie transaction mémo (PUNCH <date>) sur devnet. Tu reçois un ticket façon papier : heure, pays, règle 92/3/5, tampon on-chain.

Étape 4

Teste les fonctionnalités d'argent

  • Missions → Payer quelqu'un : bloque de vrais fonds dans le trésor.
  • Une mission → Être payé : le trésor envoie la part du travailleur.
  • Argent → Échanger : deux vrais transferts à taux fixe.
  • Argent → Garder/Relâcher SKR : vrais transferts SPL, frais réel 1,5 % au retrait.
  • Accueil → Dire bonjour : le trésor te paie 0,10 $ USDC.
  • Réglages/Split → Quitter le réseau : vraie transaction de sortie, décrément honnête.
Étape 5

Ce qu'il faut regarder

  • Chaque action doit déclencher la fenêtre de signature du wallet.
  • Adresse du trésor : FUiCbnDhEEJtz9Zcj66hGB54iGMGeyjRKD7CsTwpihJn — vérifie sur un explorateur devnet.
  • Le globe (onglet Monde) a une vraie physique de glissement.
  • Essaie le mode d'emploi interactif depuis Réglages.
  • Essaie le thème Gold dans Réglages.
