Phase 0 — Hackathon CLOCK IN (fait)

  • ✓App native Expo/React Native, clone fidèle de l'app de base.
  • ✓Pointage quotidien avec vraie transaction mémo signée (Seed Vault, devnet).
  • ✓Globe avec vraie physique de rotation (drag, momentum, damping exponentiel).
  • ✓Thème premium Solana Seeker Mobile Gold.
  • ✓Bouton « Quitter le réseau » avec vraie transaction obligatoire.
  • ✓Économie réelle sur devnet : trésor + mints SPL, tous les mouvements d'argent sont de vraies transactions.
  • ✓Frais protocole réels sur entrée/sortie et retrait.
  • ✓Nouvel habillage visuel : « CLOCK IN », ticket papier, mode d'emploi interactif.
  • ✓Documentation complète.

Sprint 20 septembre — fiabilité et habillages (fait)

  • ✓Crash au lancement réparé : polyfill Buffer chargé avant expo-router (bundle Hermes embarqué).
  • ✓Seed Vault signe, l'app soumet (5 tentatives) puis confirme — plus de « validée côté vault, refusée côté app, rien on-chain ».
  • ✓Zéro simulation : session perdue = message clair, jamais de chiffres modifiés en douce. Check de SOL avant signature.
  • ✓Reçus vérifiables pour tous les flux, signature cliquable vers l'explorer, navigation auto après swap/stake/unstake.
  • ✓Habillages A/B/C fidèles : police globale, formes, et compositions distinctes (anneau or A, ticket pointillé B qui s'enfonce, onglets hardware C).
  • ✓4 thèmes × 3 habillages = 12 apparences, palettes exactes du CSS source, boutons A B C dans la barre du haut.
  • ✓Écran de veille miroir (10/30/60 s) : le style de ta combinaison, horloge en direct.
  • ✓APK signé arm64 buildé localement, installé sur Seeker — rien à installer pour le jury.
Décision du 20 sept. — Le jury est présenté avec l'app sur SPL standard devnet (déjà vivant : trésor, mints, tous les flux signés vérifiables). Le programme Anchor de staking reste en Phase 1 : plus de vérifiabilité, pas un prérequis de démo.

Phase 1 — Juste après le hackathon

  • ○Programme Solana dédié (Anchor) pour le staking — un compte on-chain par utilisateur.
  • ○Petit serveur backend pour le trésor (la clé ne doit plus être dans l'app).
  • ○Vraies missions géolocalisées avec vérification de présence.
  • ○Système de réputation des Seekers au-delà du rang par SKR misé.

Phase 2 — Mainnet

  • ○Basculer sur le vrai mint mainnet Solana Mobile Seeker (SKR).
  • ○USDC / USDT mainnet standards.
  • ○Conformité KYC minimale si paiements réels vers fiat.
  • ○Programme de staking audité avant tout dépôt réel de valeur.

Phase 3 — Écosystème Nexus complet

  • ○Intégration de PLI comme second verbe de l'écosystème.
  • ○Écran « Atelier » commun PUNCH + PLI.
  • ○Trésorerie et pool de stakers partagés, reporting transparent.

Ce qui ne changera pas

  • La règle 92/3/5 est affichée sur chaque reçu, jamais cachée.
  • Aucune géolocalisation précise n'est jamais stockée — seulement le pays.
  • Aucune fonctionnalité qui touche à l'argent n'est simulée.
