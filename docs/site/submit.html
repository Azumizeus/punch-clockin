Pourquoi PUNCH vise le prix SKR

Staker du SKR donne un rang (Silver 1 000 · Gold 5 000 · Guardian 25 000) qui ouvre les missions mieux payées — vraie utilité, zéro nouvelle offre. Le retrait porte des frais honnêtes de 1,5 %, les frais protocole rachètent du SKR pour les détenteurs.

L'APK de la Release v1.6.6 a été construit avec le gabarit « démo trésor » : le secret GitHub TREASURY_SECRET_DEVNET n'était pas configuré au moment du build. Correction (5 min) : 1. Settings → Secrets → Actions → New repository secret · 2. Nom TREASURY_SECRET_DEVNET, valeur : le JSON des 64 octets du trésor (généré dans cur.txt, non versionné) · 3. git tag v1.6.7 && git push origin v1.6.7 → la Release se reconstruit avec le vrai trésor · 4.
