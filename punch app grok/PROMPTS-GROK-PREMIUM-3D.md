# Prompts Grok — PUNCH Premium · UX/UI 3D vectorielle · BIBLIOTHÈQUE COMPLÈTE

Analyse du projet (15 écrans + système) : `language`, `connect`, `accueil (index)`,
`board/missions`, `shift`, `receipt`, `history`, `wallet`, `split (la part)`,

USDC `#8aa0b3`, USDT `#8aa392`, SKR `#d7d2cb`.

## 0. BLOC STYLE MAÎTRE — coller au début de CHAQUE prompt

```
Premium 3D vector mobile app UI design for "PUNCH", a daily clock-in app on Solana.
Style: flat vector shapes with soft 3D depth, isometric tilt ~5°, clay + brushed
metal materials, studio lighting, soft long shadows, high-end fintech look,
ultra-clean composition, dark near-black background #0b0a07, metallic gold accents
#d4af37 with highlight #f3dc8e and deep gold #8a6d1f, ivory paper cards #f2e6c8,
Fraunces serif display type, IBM Plex Mono micro-labels, minimal readable text only.
No photorealism, no clutter, no garbled paragraphs of text.
```

**Négatif :** `photorealistic photo, stock photo, watermark, blurry, gradient banding, lorem ipsum walls of text, neon cyberpunk`

**Ratios :** `9:16` écrans · `1:1` icônes/badges · `16:9` hero marketing · `4:5` macro objets.

## Conseils d'usage Grok

1. **Texte** : 2–4 mots lisibles max par écran, sinon `all labels blurred placeholder`.
2. **Cohérence** : ne change JAMAIS le bloc style entre deux générations d'une même série ; varie seulement la partie après `+`.
3. **Trop photoréaliste ?** ajoute `flat vector illustration, Figma-style, solid shapes`.
4. **Une identité = une palette** : Or (défaut) ou Nuit (§32) — jamais un mélange.
5. **Pour l'implémentation** : un rendu Grok est une *cible visuelle* — le code réel vit dans `punch-native/lib/punch/theme.ts` (13 tokens × 2 thèmes), `looks.ts`, `skin3d.ts` et `components/Skin3D.tsx`.
